AGENTS.md — Operating contract for the Obsidian Vault
This repository is not a software repo. It's a Second Brain
(Tiago Forte) built on Obsidian. Any agent working here operates on
one person's notes, not on code: the cost of a mistake isn't a red
test, it's lost, misfiled, or duplicated information.
Root rule: never destroy or reorganize information unless the
human explicitly asked for it.
1. What this Vault is
A system for capturing and reusing knowledge, based on two frameworks
by Tiago Forte:
CODE — the flow: Capture → Organize → Distill →
Express.
PARA — the storage: Projects → Areas → Resources →
Archive.
Design premise: the human brain is great at creating ideas and terrible
at remembering them. The Vault exists so information lives outside,
sorted by when and what you'll use it for, not by topic.
