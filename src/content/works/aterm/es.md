---
shortDescription: "Una terminal web interactiva para portfolios."
---

**aterm** es un sitio web estático o portfolio que simula una terminal. Sin embargo, la experiencia mejora considerablemente cuando los visitantes pueden interactuar escribiendo comandos y obtener resultados, similar a una terminal real. Puedes llamarlo Terminal Falso, ya que no ofrece las capacidades completas de un shell real, como SSH.
