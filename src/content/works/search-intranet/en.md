At the José Antonio Echeverría University (CUJAE) in Havana, Cuba, there is a search engine for the Intranet. This engine is not only efficient in searching and locating relevant information, but it also interacts with a Lightweight Directory Access Protocol (LDAP). In the case of CUJAE, this allows the search engine to access directory information, such as user details and network structure, to provide more accurate and personalized search results. It’s worth noting that this search engine is only available on the internal network of the university campus.
